# Vehicle Registration System

A Java console application for managing vehicle registrations.

## Features

1. Register a vehicle (Car, Motorcycle, or Truck)
2. View all registered vehicles
3. Search by plate number
4. Search by owner name
5. Update vehicle details
6. Delete a vehicle
7. Change registration status (Pending, Approved, Rejected)
8. Count registered vehicles
9. Filter vehicles by type
10. Exit

## Java concepts

- Object-oriented programming
- Encapsulation
- Inheritance
- Polymorphism
- ArrayList collections
- Exception handling

## How to run

1. Open the project in IntelliJ IDEA or another Java IDE.
2. Compile and run `Main.java`.
3. Follow the numbered menu in the console.

**Note:** Vehicle data is stored in memory and is cleared when the application exits. This is a student-project implementation, not a production registration system.
